### 关键 Bug 修复（可复用排错经验）
1. **TypeORM `design:type: Object`**：`string | null` 联合类型会让 MySQL 报 `not supported`，导致 DB 连接失败进 degraded 模式。→ 所有 nullable 字符串列显式加 `type: 'varchar'`。
2. **维护开关 JSON 字符串真值陷阱**：种子写入 `"false"`（字符串）在 JS 是 truthy，导致所有请求被 503。→ `app.ts` 布尔归一化 + `schema.sql` 改用 `CAST('false' AS JSON)`。
3. **订阅加额未生效**：原 `grantPlanByOrder` 只插订阅不写额度，new 套餐后 remaining 仍为 0。→ 新增 `grantQuota/revokeQuota`，支付成功叠加 / 退款扣回。
