# Web Image Uploader 退款政策

1. 购买后尚未使用相关权益的订单，可在支付后 7 日内申请退款。
2. 已使用的任务次数、已消耗的中转流量或已完成的 ZIP 任务，按实际消耗扣除后处理退款。
3. 因系统故障导致任务未完成且未能恢复的，退回对应额度或按原支付渠道退款。
4. 月度/年度订阅取消后不再自动续费，当前周期权益通常持续到到期日；退款按未使用部分和支付渠道规则处理。
5. 微信、支付宝、PayPal 退款均由服务端发起原路退款，到账时间以支付平台为准。
6. 退款申请需要提供订单号和账号邮箱，不得提交银行卡完整信息或支付密码。
