## 二、浏览器手工验收步骤（建议按序执行）

### 步骤 0：加载与配置
1. `chrome://extensions` 开发者模式 → 加载已解压 `web-image-uploader` 目录，无报错即加载成功。
2. 设置页：先开启 **Mock 模式** 走通全流程（见步骤 1）；再按 README 配置 Google Cloud（启用 Photos Library API、OAuth consent screen Testing + 测试用户、Chrome 扩展类型 Client ID 粘贴进设置页），关闭 Mock。

### 步骤 1：Mock 模式端到端（无凭据验证队列/UI/状态机）
| # | 操作 | 期望 |
| --- | --- | --- |
| 1.1 | 打开任一图集网页（建议 >20 图），点插件图标 | Popup 自动扫描，列表出现图片缩略图、分辨率、类型 |
| 1.1b | 设置页勾选「扫描时自动滚动到页面底部」 | 懒加载长页点扫描能自动滚动扫到全部图（不再首屏 0 张） |
| 1.1c | 底部上传目标选「加入指定相册…」 | 出现已登录账号本插件创建的相册下拉列表，可选中并提示 |

## 四、已知限制（如实声明）
1. 真实 OAuth 与 Google Photos 上传**无法在本开发环境完成自动化验证**，需本人账号按步骤 3 走一遍（Mock 已覆盖同样 UI/队列路径）。
2. 严格防盗链（无 CORS 且校验 Referer）的图片读取受浏览器安全模型限制，会返回明确失败原因。
3. Testing 态 OAuth refresh token 约 7 天过期，需周期性重新登录。
4. 上传占用 Google 存储空间；单任务默认上限 500 张。
