# 宝塔部署文档

## 环境

- Node.js 22+
- MySQL 8+
- Nginx
- PM2
- HTTPS 域名

## 后端

```bash
cd backend
cp .env.example .env
npm ci
npm run build
mysql -u root -p web_image_uploader < schema.sql
pm2 start dist/app.js --name web-image-billing
pm2 save
```

`.env` 必须填写随机 `JWT_SECRET`、MySQL 凭据、`APP_BASE_URL` 和管理员邮箱。生产环境设置 `NODE_ENV=production`，开发登录接口会自动关闭。

支付环境变量仅作为初始配置模板，真实密钥建议通过管理后台保存并脱敏展示。微信需要商户私钥文件、证书序列号和 APIv3 密钥；支付宝需要应用私钥和支付宝公钥；PayPal 需要 Client ID、Secret 和 sandbox/live 环境。所有渠道默认关闭，完成小额沙箱/生产联调后再启用。

## Nginx

将 `/api/` 反向代理到 `127.0.0.1:8787`，上传请求体限制至少 25MB，启用 HTTPS。微信、支付宝和 PayPal 的 Webhook 地址必须公网可访问且使用 HTTPS。

## 管理后台

```bash
cd admin
npm ci
npm run build
```

将 `admin/dist` 配置为 Nginx 静态站点；生产环境通过 `localStorage.pgx_api_base` 或构建环境变量指向收费 API 域名。

## 上线前检查

- 数据库备份和恢复演练；
- JWT_SECRET 不提交 Git；
- 支付私钥只存服务器并脱敏显示；
- Webhook 验签、幂等和主动查单测试；
- 图片临时文件清理任务；
- 隐私政策、条款、退款政策和账号删除入口可访问；
- Chrome OAuth 使用正式商店扩展 ID；
- 用 1 分钱/沙箱订单完成真实回调联调。
