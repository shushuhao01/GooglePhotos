Google 账号与授权

Google Cloud Console → APIs & Services → Credentials → 创建「Chrome 扩展程序」类型客户端，将 Client ID 粘贴于此。自用可保持 OAuth consent screen 为 Testing 并把本人账号加入测试用户。

关键：在 Google Cloud 创建 OAuth Client 的「类型」必须选 Chrome 扩展程序（不要选 Web 应用），并把上面的 redirect URI 加到客户端的「已获授权的重定向 URI」里；同时 OAuth consent screen 设为 Testing 且把你本人在「测试用户」中，否则授权会被拒绝。
